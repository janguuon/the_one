# THE ONE 시제품 개발 결과

2026년 10월 16일 기준. Godot **4.5.2.stable.official.6ce3de25a**, GDScript, Windows. M1과 M2의 플레이 가능한 시제품을 구현했다.

## 실행과 조작

프로젝트 폴더에서 다음 명령을 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\run_game.ps1
```

J 또는 Enter로 시작한다. 이동은 WASD/방향키, 공격은 J, 회피는 Space/K, 일시정지는 Esc, 빠른 재도전은 R, 판정 표시는 F1이다. 게임패드는 왼쪽 스틱, 서쪽 얼굴 버튼 공격, 남쪽 얼굴 버튼 회피, Start 일시정지로 매핑했다.

편집기는 실행 명령에 `-Editor`를 추가한다. 엔진은 `.tools/godot/`의 공식 Standard 배포본이며, 소스만 전달할 때는 별도로 Godot를 준비하거나 `-GodotPath`를 지정한다. 공식 배포 출처는 [Godot 4.5.2 아카이브](https://godotengine.org/download/archive/4.5.2-stable/)다.

## 구현된 범위

- 640×360 고정 전장, 1280×720 기본 창, 최근접 필터와 정수 확대.
- 지면 좌표 기반 이동, 타원 경계 법선 투영, 몸체 충돌과 회피 통과·종료 분리.
- 잿빛 검 9/6/18틱 공격, 24틱부터 회피 취소, 6스택 비기.
- 기본·비기·화염·공명 스냅샷과 시작 시 자원 소비.
- 새 입력과 6틱 버퍼, 회피 우선, 자원으로 공격 종류가 바뀔 때 예약 무효화.
- 화염 기운의 체력 임계치 예약, 회복 중 방출, 24틱 비행, 접촉 획득·보충, 600틱 수명과 바닥 최대 두 개.
- 화염의 네 번 지속 피해와 갱신, 행동별 단일 피격·스택 적립.
- P1 재의 발톱, 첫 균열, 최초의 맥동. 시드 기반 셔플 백과 방향 추적 종료.
- 피해 후 무적, 피격 경직, 동시 피해 배치와 시제품 동시 사망 실패.
- HUD, 다음 공격 표시, 시작·일시정지·사망·시제품 완료·재도전 화면.
- 도형으로 구성한 어두운 경기장과 인물 실루엣, 공격 예고, 화염 도형과 최소 피격 효과.

최종 EITR 분위기의 도트 아트, 소리 자산, 키 재지정, 다른 무기·속성·각인, 다른 페이즈, 연습, 영구 저장은 아직 구현하지 않았다. 게임패드 매핑은 구현했으며 실제 장치로 누르는 검증은 남아 있다.

## 구조와 데이터

| 파일 | 역할 |
|---|---|
| `data/combat.json` | 플레이어·검·화염·P1 수치의 원본 |
| `scripts/combat_geometry.gd` | 타원 경계, 예고와 판정에 공유하는 도형 연산 |
| `scripts/combat_model.gd` | 렌더링과 분리된 60Hz 전투, 자원, 보스, 기운, 결과 |
| `scripts/main.gd` | 실제 입력, 히트스톱과 일시정지, 렌더링, HUD와 메뉴 |
| `scenes/main.tscn` | 실행 장면 |
| `tools/run_game.ps1` | 프로젝트·편집기 실행과 로컬 캐시 격리 |
| `tools/test_game.ps1` | import, 테스트 실행, 오류 로그와 종료 코드 검사 |

설계 수치는 바꾸지 않았다. 경계 밖 위치는 법선 방향으로 투영하고, 기운 착지는 다음 짧은 발톱까지 고려해 보스 발점에서 68px 이상 떨어지게 배치했다. 내부 피해는 0.001 단위로 정규화한 수치이며 최종 표시 체력은 올림한다.

테스트용 `debug_` 함수는 희귀 상태를 준비하는 데 사용하며 일반 입력·화면에서는 노출하지 않는다. 기본 플레이에는 무적, 공격력 증가, 보스 체력 감소 등의 테스트 보정을 사용하지 않는다.

## 검증 결과

검증 실행 명령은 README에 있다. 구체적인 테스트 코드는 `tests/`에 남겼다.

- 전투 규칙: `tests/combat_tests.gd`의 103개 검증 통과. 이동, 무적 경계, 취소, 버퍼, 피해와 자원, 기운 생애, 지속 피해의 마지막 틱, 패턴 예고와 판정, 종료와 재시작을 포함한다.
- 실제 장면 연결: `tests/scene_integration.gd`의 33개 검증 통과. 시작, 새 누름과 키 반복, 일시정지와 기운 수명 정지, 히트스톱과 입력 우선, 결과와 재도전, 패드 버튼 이벤트 연결을 확인했다. 전투 검증과 합계 136개이며 물리 입력 장치를 사람이 조작한 테스트는 아니다.
- 정상 입력 완주: `tests/playthrough.gd`가 시드 1·2·3·7·19에서 기본 체력 100, 보스 체력 1000, 원래 피해량으로 전부 P1 완료. 각 3800~4417 전투 틱, 약 63~74초. 히트스톱과 화면의 벽시계 시간은 이 순수 모델 테스트에 포함하지 않는다.
- 이 완주에서는 이동·공격·회피 명령만 보냈고, 체력이나 위치를 직접 변경하거나 피해를 주입하지 않았다. 다섯 시드 모두 무피격이며 화염 세 개를 획득했다. 기본·비기·화염을 모두 사용했고 시드 2·19는 공명도 사용했다.
- 같은 정상 수치에서 아무 조작을 하지 않는 플레이어는 사망했다.
- 실제 Godot OpenGL 창을 실행하고 전투와 시작 화면을 PNG로 캡처해 확인했다. 한국어 표시, HUD, 발톱 예고, 창 크기와 전장 위치를 확인했다.
- 헤드리스 실제 장면이 120틱 동안 실행되고 오류 없이 종료되는 smoke 확인을 수행했다.

자동 정책의 무피격 완주는 패턴을 학습한 입력으로 피할 수 있음을 확인한다. 사람의 첫 플레이 난도나 재미를 검증했다는 뜻은 아니다. 물리 키보드·게임패드로 사람이 처음부터 끝까지 플레이한 테스트, 다양한 GPU의 프레임 시간 측정은 남아 있다.

## 다음 M3 작업

1. 현재 모델의 플레이어 공격·피해·기운 계약을 유지하면서 P2~P5 패턴 데이터를 추가한다.
2. 페이즈 체력 구간과 전환, 잔류 판정 제거, 회복과 재개 입력을 연결한다.
3. 나머지 속성과 다음 공격 표시를 확장한다. 첫 추가 대상은 서리다.
4. 정식 도전과 잔향 연습을 prototype 모드와 분리한다. 정식 P5 동시 사망 성공과 현재 시제품의 동시 사망 실패를 섞지 않는다.
5. 경로를 제한하는 장판·돌진·잔향 템플릿의 시간 경로 검증을 추가한다.
6. 다섯 페이즈 연속 완료와 연습 결과 분리를 검증한 뒤 M4의 무기·각인을 연결한다.

기존 설계 문서의 시간과 수치는 전체 게임을 위한 시작값이다. 이번 P1 시제품만으로 전체 8~12분 목표나 무기 간 밸런스를 확정하지 않는다.
